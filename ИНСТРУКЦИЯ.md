# Как работать с проектами OpenComputers

## Что здесь есть

- `.luarc.json` — включает подсказки для этой папки.
- `oc-api\` — описания API: OpenComputers 1.8.3, OpenOS 1.8.3 и компоненты модов из сборки
  (OpenSecurity, Energy Control, IndustrialCraft 2, Railcraft). Подробнее — в [oc-api/README.md](oc-api/README.md).

Оба нужны только редактору. **В игру их не копировать и не менять.**

## Где создавать проекты

В VS Code всегда открывай **всю папку** `D:\prog\Minecraft\opencomputers` (Файл → Открыть папку).
Каждый проект — своя подпапка, со структурой как будет в игре:

```
D:\prog\Minecraft\opencomputers\
├── .luarc.json      ← включает подсказки
├── oc-api\          ← описания API
├── farm\            ← проект
│   ├── main.lua
│   ├── services\FarmService.lua
│   └── help\Logger.lua
└── miner\           ← другой проект
    └── main.lua
```

## Работает ли это только здесь

Подсказки работают во всех файлах и подпапках внутри этой папки — если в VS Code открыта она целиком.
Если открыть, например, только `farm`, подсказок не будет: файл настроек окажется выше открытой папки.

Чтобы работало в другом месте, скопируй туда `.luarc.json` и папку `oc-api`.
Можно перенести и всю папку `opencomputers` целиком — перенастраивать ничего не нужно.

## Проект из нескольких файлов

Файл с функциями (`farm\services\FarmService.lua`):

```lua
---@class FarmService
local FarmService = {}

---Сажает семена.
---@param count number сколько посадить
function FarmService.PlantSeeds(count)
    print("Сажаем семена", count)
end

return FarmService
```

Подключение в `farm\main.lua`:

```lua
local FarmService = require("services.FarmService")

FarmService.PlantSeeds(5)
```

- Строки с `---` — обычные комментарии, игра их пропускает. А редактору они нужны:
  - `---@class` — чтобы подчёркивались опечатки в именах функций (`FarmService.PlantSed()`);
  - `---@param` — чтобы проверялись аргументы и показывалась подсказка при вызове.
- Редактор ловит синтаксические ошибки в любом файле, лишние или неверные аргументы, опечатки в именах.
- Опечатку в пути `require("services.FarmSrvice")` редактор **не** подчёркивает. Признак — после точки пропали подсказки.

## Компоненты

```lua
local component = require("component")

local gpu = component.gpu               -- тип известен сам, после точки будут подсказки
gpu.set(1, 1, "Привет")

---@type ComponentRedstone
local rs = component.proxy(component.list("redstone")())   -- для proxy тип указываешь сам
```

Класс называется `Component` + имя компонента: `ComponentGPU`, `ComponentRedstone`, `ComponentInventoryController`…

## Как переносить в игру

Жёсткий диск каждого компьютера — это папка в сохранении:

```
D:\potrable\PrismLauncher\instances\1.12.2\minecraft\saves\Империя\opencomputers\<адрес диска>\
```

Внутри то же, что видишь в игре: `home`, `bin`, `lib`…
Какой диск у какого компьютера: в игре выполни `df /home` — в первой колонке будет адрес диска
(или его имя, если диск подписан). Сейчас в мире два диска: `e54d1166-…` (там твои скрипты) и `8d9e9a6e-…`.

1. Скопируй папку проекта (например, `farm`) в `<адрес диска>\home\`.
2. В игре: `cd /home/farm`, затем `main`.
   Запускать нужно **из папки проекта**: `require("services.FarmService")` ищет файл относительно текущей папки.
   Если запустить `/home/farm/main.lua`, находясь в другой папке, будет ошибка `module ... not found`.
3. Поменял файл-модуль — сделай `reboot`. Модули кешируются до перезагрузки компьютера,
   и без неё выполнится старая версия.

### Чтобы игра сразу видела скопированные файлы

По умолчанию OC держит файлы диска в памяти и записывает их только при сохранении мира,
поэтому скопированное снаружи игра увидит только после перезахода в мир.

Чтобы видела сразу: **закрой игру** и в файле

```
D:\potrable\PrismLauncher\instances\1.12.2\minecraft\config\opencomputers\settings.conf
```

замени `bufferChanges=true` на `bufferChanges=false`.

## Что значат подчёркивания

- **Красное** — ошибка синтаксиса, скрипт не запустится.
- **Жёлтое** — подозрительное место: опечатка в имени, аргумент не того типа, забытый `require`,
  или «здесь может быть nil» (например, `io.open` вернёт nil, если путь неверный — проверь через `if file then`).
- Наведи мышку — покажет описание функции или причину предупреждения.
- **Ctrl+Пробел** — список подсказок, **Ctrl+клик** — перейти к функции.

## Если подсказки не работают

1. Проверь, что в VS Code открыта вся папка `D:\prog\Minecraft\opencomputers`.
2. Внизу справа должно быть написано **Lua**.
3. Ctrl+Shift+P → **Reload Window**.

## Версия Lua

Стоит Lua 5.3 — как у процессора по умолчанию. Если переключишь процессор на Lua 5.2
(Shift+ПКМ процессором в руке), замени в `.luarc.json` `"Lua 5.3"` на `"Lua 5.2"`.
